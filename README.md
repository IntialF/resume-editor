# 简历编辑器

一个纯前端、零构建的网页简历编辑器：可视化填写、实时 A4 预览、精确分页、一键导出 PDF。所有数据只保存在你自己的浏览器里，不上传服务器。

## 功能

- **可视化编辑**：基本信息、工作经历、项目经历、教育经历、专业技能、荣誉奖项、自定义模块。
- **灵活调整**：模块和条目都可新增、删除、上移/下移、拖拽排序；模块可重命名、临时隐藏。
- **文字加粗**：选中文字点 `B` 或按 `Ctrl/⌘ + B` 即可加粗，再按一次取消；也可直接写 `**文字**`。所有字段通用。
- **技能整块**：专业技能是一个多行文本框，每行一条技能，预览自动加小圆点，长句换行后整齐对齐；行首写 `**类别**：` 可加粗分类名。
- **排版设置**：3 套模板（现代 / 经典 / 简约）、主题色、字号、行距、条目间距、模块间距、页边距、字体、页码。字号与间距既有预设，也可选「自定义」用滑块或数字框精确调整，点回预设即可恢复默认。
- **实时预览**：按真实 A4 页面（794 × 1123 px）显示，屏幕所见即打印所得；模块标题不与首条目分离，超长条目自动拆分，不会溢出纸张。
- **导出 PDF**：两种路径——打印/另存为 PDF（矢量文字、可选中、离线可用），或直接下载 `.pdf` 文件（渲染组件已本地化，离线可用）。
- **数据备份**：可导出 / 导入 JSON，支持载入示例、清空全部。
- **移动端适配**：820px 以下自动切换为「编辑 / 预览」标签布局，工具栏收纳，表单单列，触控尺寸优化。

## 快速开始

直接双击 `index.html` 用浏览器打开即可，无需安装任何依赖，也无需联网。

如需通过本地服务访问：

```bash
cd E:/简历编辑器
python -m http.server 8080
# 然后打开 http://localhost:8080
```

浏览器建议使用最新版 Chrome / Edge。

## 使用说明

### 编辑与排序

- 左侧直接填写，右侧实时同步。输入框上方支持选中文字加粗。
- 模块标题可点击重命名；`◉` / `◎` 控制该模块是否出现在简历里。
- 每个模块、条目都有 `↑` `↓` `✕` 按钮；PC 端还可拖拽 `⠿` 手柄排序。触屏请用 `↑` `↓`。
- 「描述要点」每行一条，预览中自动变成项目符号。建议用数字量化成果。

### 技能模块

专业技能与其他模块不同：**整个模块只有一个文本框**，每行写一条技能，例如：

```
**前端开发**：JavaScript / TypeScript、Vue 3 / React，具备大型 SPA 架构经验
**工程化**：Vite / Webpack / Rollup、pnpm Monorepo、CI/CD
```

`**类别**：` 会让类别名加粗。留空行会被忽略，顺序即为预览顺序。整个技能区在分页时作为一个整体块处理。

### 导出 PDF

- 点顶部 **一键导出 PDF** → 在系统打印窗口选择「另存为 PDF」，边距选「无」、缩放 100%、勾选「背景图形」。推荐这种方式，文字清晰且可选中。
- 点按钮右侧 `▾` → **直接下载 PDF 文件**，一键生成 `.pdf`，不需要联网。
- 两种方式的页数和排版与屏幕预览一致（A4，210 × 297 mm）。

### 移动端

窗口宽度小于 820px 时自动切换布局：顶部「编辑 / 预览」标签可来回切换；数据导入导出等操作收进顶栏「⋯」；预览默认整页适应宽度，点「放大阅读」可按 100% 查看并左右滑动。

## 数据存储与隐私

- 你填写的内容保存在**当前浏览器的 localStorage**（键名 `resume-editor-v1`），不会写入项目文件，也不会发往任何服务器。项目中没有网络请求或数据上报。
- 换浏览器 / 设备、清理浏览器数据都会导致内容丢失，请用「数据 → 导出简历数据」备份 JSON。
- localStorage 按域名隔离。部署到 GitHub Pages 后，别人打开页面看到的是内置示例，看不到你本地填写的内容。
- `app.js` 中的「张明 / 138 0000 0000 / example.com」是**虚构示例数据**，不是任何人的真实信息。
- 不要把导出的 `.json` / `.pdf` 放进项目目录并提交；`.gitignore` 已默认排除它们以及 `.workbuddy/`、验证截图。

## 项目结构

```
.
├── index.html                 页面结构
├── styles.css                 界面、A4 纸张、响应式与打印样式
├── app.js                     数据模型、编辑交互、分页引擎、导出逻辑

└── vendor/
    ├── html2canvas.min.js     html2canvas 1.4.1（MIT）— PDF 截图渲染

```

## 实现要点

- **零依赖原生 JS**：单一状态 `state`（`basics` / `sections` / `settings`）。输入时只更新状态与预览，不重建表单，避免打字时失焦。
- **分页引擎**：内容拆成测量单元 → 离屏测量实际高度 → 贪心装入固定 A4 页面。模块标题与首个条目绑定，超长块按要点自动拆分。
- **所见即所得**：`@page { size: 794px 1123px; margin: 0 }` 与屏幕纸张使用同一 px 尺寸；打印样式隐藏所有编辑器 UI，只输出纸张。
- **导出**：打印走浏览器原生 PDF（矢量）；直接下载用本地 html2canvas 逐页截图 + jsPDF 合成 A4 多页 PDF，加载失败时才回退公共 CDN。
- **加粗**：采用 `**文字**` 轻量标记，先 HTML 转义再解析为 `<strong>`，不会注入脚本；兼容两种导出路径与分页测量。

## 部署

纯静态站点，可直接把整个目录传到 GitHub Pages、Netlify、Vercel 或任意静态托管，无需构建步骤。入口是 `index.html`，`vendor/` 目录需一并上传（直接下载 PDF 要用到）。

## 常见问题

**导出的 PDF 模糊吗？** 用「打印 / 另存为 PDF」得到的是矢量文字，放大依然清晰。直接下载的方式会把每页渲染成图片，适合快速分享，放大后清晰度略低。

**打印出来多了一页空白？** 请确认打印窗口里边距选「无」、缩放 100%、纸张为 A4。页面已通过 `@page` 指定尺寸，不需要额外设置。

**手机上能不能拖拽排序？** 不能，浏览器对触屏 HTML5 拖拽支持有限，请用条目上的 `↑` `↓` 按钮。

**改了字号后分页变了吗？** 会实时重算分页。字号或间距过大时页数会增加，属正常现象；点回预设即可恢复。
